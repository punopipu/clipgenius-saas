1. Visión General del Sistema y Arquitectura Integrada

ClipGenius & AuditAI es una infraestructura SaaS integral concebida para automatizar el análisis estratégico de textos, minutas ejecutivas, audios y contenido audiovisual mediante inteligencia artificial. Su diseño prescinde de interfaces sobrecargadas o bases de datos vulnerables, enfocándose exclusivamente en la velocidad de respuesta, el rigor analítico y la seguridad criptográfica.

1.1 Componentes Principales de la Solución

El ecosistema operativo está compuesto por cuatro capas coordinadas de manera sinérgica:

  • Capa de Captura (Tally Form Engine): Interfaz de venta y registro que gestiona los parámetros de pedido sin almacenar datos financieros sensibles en servidores propios.
  • Capa de Automatización (Make Integration Layer): Motor de reglas que escucha las transacciones confirmadas, formatea la solicitud y genera los tokens firmados con un timestamp UNIX en formato hexadecimal.
  • Capa de Procesamiento Serverless (Vercel Node.js Runtime): Endpoints distribuidos que ejecutan la validación criptográfica HMAC-SHA256 en memoria volátil y procesan las instrucciones según el plan del usuario.
  • Capa de Cliente (Minimal Frontend Interface): Consola web ligera optimizada para la menor latencia posible y adaptabilidad total en navegadores de escritorio y móviles.

1.2 Misión y Casos de Uso Corporativos

El sistema abarca múltiples casos de uso empresariales e individuales de alto rendimiento:

  • Agencias de Marketing y Creadores: Extracción de fragmentos de alta retención para videos cortos (Reels, TikToks, Shorts) a partir de podcasts o grabaciones extensas.
  • Consultoras y Bufetes Legales: Síntesis inmediata de notas de reuniones, actas de mediación y documentos técnicos con detección implícita de compromisos y plazos.
  • Equipos Directivos y Gerenciales: Conversión de conversaciones informales o minutas desordenadas en reportes ejecutivos estructurados con matriz de riesgos.

2. Protocolo Criptográfico HMAC-SHA256 y Gestión de Licencias

El acceso a la plataforma no depende de contraseñas tradicionales ni de credenciales estáticas. En su lugar, utiliza un estándar militar de validación simétrica basado en tokens unívocos firmados.

2.1 Anatomía del Token de Acceso

Cada código emitido presenta una estructura delimitada por guiones con tres segmentos fundamentales:

[PREFIJO_PLAN]-[TIMESTAMP_HEXADECIMAL]-[FIRMA_HMAC_TRUNCADA]

Ejemplo representativo: BUSINESS-670e5b80-a8f92c

  • Prefijo del Plan: Identifica el nivel de servicio asignado (BASIC, PRO o BUSINESS).
  • Timestamp Hexadecimal: Representación en base-16 de la fecha y hora exacta en que el código fue expedido por el motor de automatización.
  • Firma HMAC Truncada: Hash de 256 bits generado a partir de la combinación del plan, el timestamp y la clave secreta privada (SAAS_SECRET_KEY), recortado para facilidad del usuario.

2.2 Algoritmo de Verificación en Servidor

Al enviar una solicitud desde la consola, el backend ejecuta los siguientes pasos de comprobación antes de consumir recursos de cómputo:

  1. Sanitización del texto ingresado eliminando espacios accidentales.
  2. Descomposición del string mediante expresiones regulares estrictas.
  3. Recálculo de la firma matemática utilizando la clave secreta almacenada en las variables de entorno de Vercel.
  4. Comparación en tiempo constante para evitar ataques de temporización (timing attacks).
  5. Conversión del timestamp hexadecimal a milisegundos y cálculo de la diferencia respecto a la hora actual del servidor.
  6. Rechazo inmediato con código HTTP 401 si la firma no coincide o HTTP 403 si transcurrieron más de 30 días naturales.

4. Guía de Respuestas y Códigos del Servidor

Si la consola no arroja el análisis esperado, consulta la siguiente tabla de estados HTTP del sistema:

  • HTTP 400 Bad Request - "El código de acceso es obligatorio"
    Ocurre cuando el campo del código se envía vacío o la variable del cuerpo JSON no coincide con accessCode.
  • HTTP 401 Unauthorized - "Código de acceso no autorizado o falsificado"
    El código ingresado no cumple con la firma HMAC esperada. Verifica que no hayas alterado caracteres ni agregado espacios al copiar.
  • HTTP 403 Forbidden - "Tu suscripción mensual ha expirado"
    Han transcurrido más de 30 días desde la emisión del token. Se requiere contratar una renovación para generar una nueva clave activa.
  • HTTP 200 OK - "Acceso concedido"
    La firma es válida y la licencia se encuentra activa. El resultado del análisis se despliega correctamente en el recuadro inferior.

Preguntas Frecuentes (FAQ)

Aclaraciones sobre facturación, privacidad y soporte del software.

¿Cómo se realiza el envío del código tras la compra?
Una vez realizada la solicitud y confirmación en el formulario de Tally, nuestro webhook automatizado procesa la transacción en Make, calcula la firma única y envía el código por correo electrónico de manera inmediata.
¿El sistema almacena el texto o los documentos que analizo?
No. Nuestra arquitectura opera mediante funciones Serverless en Vercel. Cada petición se procesa en memoria volátil de forma efímera y se desecha inmediatamente tras entregar la respuesta.
¿Puedo compartir mi código con otros miembros de mi equipo?
Los códigos de los planes Básico y Pro están pensados para uso individual. El Plan Business contempla el uso compartido entre integrantes de la misma organización durante el ciclo de 30 días.
¿Qué sucede si necesito analizar un archivo de video muy extenso?
Puedes pegar directamente la transcripción del video o el enlace público del material en el área de texto. El motor extraerá los bloques de tiempo significativos.
¿Cómo funciona la renovación mensual?
Al finalizar el periodo de 30 días, puedes acceder nuevamente a la página de contratación para generar una nueva clave con firma actualizada. Sin cobros automáticos no deseados.
